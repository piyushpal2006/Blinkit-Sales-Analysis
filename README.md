# Blinkit Sales Analysis Dashboard

## Project Overview
This project analyzes Blinkit grocery sales data using Microsoft Excel. The dashboard provides insights into sales performance, customer preferences, and product trends.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Cleaning
- Conditional Formatting

## Key KPIs
- Total Sales
- Average Sales
- Number of Orders
- Product Performance

## Key Insights
- Identified top-performing product categories.
- Analyzed sales trends across different outlet types.
- Compared customer ratings and product performance.
- Generated business insights for decision-making.
